A premium, editorial-style digital experience for **JG University**, designed to elevate institutional branding through modern web aesthetics, sophisticated micro-interactions, and high-performance engineering.

---

## ✨ Key Features

- **Editorial-First Design:** A bold visual language using *Plus Jakarta Sans* and *Inter*, focusing on high-contrast layouts and premium whitespace.
- **Sophisticated Micro-Interactions:**
  - **Magnetic Buttons:** Custom components with physical cursor tracking.
  - **Animated Mesh Gradients:** Smooth, canvas-rendered background "light beams".
  - **Glassmorphism:** Elegant semi-transparent UI layers with backdrop-blur.
- **High-Performance Motion:** Orchestrated entrance animations and parallax effects using Framer Motion.
- **Responsive Fluidity:** Adaptive layouts using CSS `clamp()` and container queries for a seamless mobile-to-desktop transition.
- **Interactive Programs Grid:** School-specific cards with mouse-aware lighting effects and dynamic student stats.

## 🛠️ Technology Stack

- **Framework:** Next.js 15 (App Router)
- **Styling:** Tailwind CSS 4.0
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Design System:** Custom "JG Excellence" tokens in `globals.css`

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone [repository-url]
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
